# 🌸 Fragre de Riva

> A luxurious e-commerce web application built for an exclusive fragrance brand, offering a seamless shopping and direct WhatsApp checkout experience.

## ✨ Features

- **Responsive Design:** Optimized for both mobile and desktop views, featuring a custom mobile bottom navigation bar.
- **Product Catalog & Details:** Browse exquisite fragrances with smooth animations and variant selections (size/volume).
- **Cart & Wishlist System:** Add items to cart or save favourites to the wishlist with real-time badge updates.
- **Discount & Coupons:** Apply coupon codes (percentage or fixed amounts) during checkout.
- **WhatsApp Checkout:** Direct order placement via WhatsApp with pre-formatted customer and order details.
- **Modern Tech Stack:** Built with Next.js App Router, Tailwind CSS, and TypeScript.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript
